# Vidrio

Una pantalla de inicio para Android con vidrio líquido, como la del iPhone pero con su propio toque.
Acá están solo las versiones para instalar (el código es privado).

Necesitás Android 12 o más nuevo.

## Instalarlo con actualizaciones automáticas (recomendado)

Vidrio se actualiza con **Obtainium**, una app gratuita que avisa cuando hay versión nueva y la instala encima, sin perder tu diseño.

1. **Instalá Obtainium.** Entrá desde el teléfono a
   [github.com/ImranR98/Obtainium/releases](https://github.com/ImranR98/Obtainium/releases),
   bajá el archivo que termina en `arm64-v8a-release.apk` (el de la última versión) y abrilo.
   Si el teléfono pregunta, dejá que el navegador instale apps.
2. **Agregá Vidrio.** En Obtainium tocá **Agregar app**, pegá esta dirección y tocá **Agregar**:

   ```
   https://github.com/nabue-ops/vidrio-descargas
   ```

3. Tocá **Instalar**. La primera vez, dejá que Obtainium instale apps.
4. **Ponelo como inicio.** Apretá el botón de inicio y elegí **Vidrio** → **Siempre**.
   Si no pregunta: Ajustes del teléfono › Apps › Apps predeterminadas › App de inicio › Vidrio.

Cuando haya una versión nueva, Obtainium te avisa: tocás **Actualizar** y listo.
En Xiaomi conviene darle a Obtainium "Inicio automático" (Ajustes › Apps › Obtainium) para que revise solo.

## Instalarlo a mano (sin actualizaciones automáticas)

En [Versiones](https://github.com/nabue-ops/vidrio-descargas/releases) bajá el `vidrio-….apk` más nuevo y abrilo.
Para actualizar, hacé lo mismo con la versión nueva: se instala encima.

## Los permisos

Vidrio **no tiene acceso a internet**: no puede mandar nada afuera del teléfono.
Todos los permisos son opcionales; sin ellos solo se apaga lo que los usa.

| Permiso | Para qué |
|---|---|
| Acceso a notificaciones | Los numeritos en los íconos, el panel de avisos y los widgets de otras apps |
| Acceso al uso | Apps sugeridas y tiempo de pantalla |
| Calendario | El widget de calendario |
| Actividad física | El widget de pasos |
| Micrófono | El asistente de voz |
| Contactos | Llamar o escribir desde la búsqueda |
| Fotos | Elegir fondos y fotos para widgets |

## Volver al inicio de antes

Ajustes del teléfono › Apps › Apps predeterminadas › App de inicio, y elegí el original.
